# Archived documents

These documents describe the earlier **Social Value RFP Response Builder**: a prompt-based tool that produced three packages (core, enhanced, localised). They were written before the Initiative Generator replaced it, and they no longer describe how the tool works.

They are kept for history only. Do not send them to the client.

For the current tool, see:

- `docs/HIGH_LEVEL_DESIGN_DOCUMENT_HLD.md` and `.docx` (version 2.0)
- `docs/LOW_LEVEL_DESIGN_DOCUMENT_LLD.md` and `.docx` (version 2.0)
- The client handover pack, shared separately as a document
